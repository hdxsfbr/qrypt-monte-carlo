End-to-end path of POST /jobs, the main request, from the Lambda Function URL to the 202 response, and the follow-up polling of GET /jobs/{id}. Each stage can short-circuit with a specific status: 401 (auth), 400 (body/validation), 429 (rate limit), 502/503 (Qrypt), 503 (queueing), 500 (anything unexpected, with request id). Simulation happens asynchronously in workers after the 202.
