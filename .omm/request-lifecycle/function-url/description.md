Lambda Function URL for qmc-<env>-api (infra/modules/api/main.tf). Auth type NONE in the default BEARER mode, with two public permissions (InvokeFunctionUrl and InvokeFunction restricted to invoked_via_function_url); AWS_IAM mode drops both and requires SigV4-signed requests. Delivers the HTTP request as a payload-v2 event (requestContext.http.method, rawPath, headers, body, isBase64Encoded).
