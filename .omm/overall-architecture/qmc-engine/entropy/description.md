src/qmc/entropy.py. EntropySource protocol (fetch() -> 1024 bytes). QryptEntropySource makes one HTTPS GET with a 3 s timeout and never exposes the token in repr; parse_response requires {"random": [base64]} decoding to exactly 1024 bytes. MockEntropySource returns a fixed block or a chosen failure and counts calls (used to prove replay never calls Qrypt). Failures raise EntropyError(cause, client_status, message); there is deliberately no local fallback.
