Pure-Python numerical engine (src/qmc/), with no AWS calls. Covers request validation, entropy sources, seed derivation (HKDF-SHA256), per-shard Monte Carlo simulation (Mersenne Twister + Box-Muller under geometric Brownian motion), exact aggregation, the Black-Scholes closed form, and an in-process pipeline that runs the same steps as the distributed workers. ALGO_VERSION = "qmc-v1" labels the exact numerical recipe.
