Standard-library command-line client for the deployed API (src/qmc/cli.py, invoked via scripts/qmc). Subcommands: health, submit, get, list, replay, wait, and local (runs the engine in-process with a given seed, no network). Reads QMC_URL and API_KEY from the environment or a .env file and sends the key only in the Authorization header. `--wait` polls GET /jobs/{id} every second until COMPLETE or PARTIAL.
