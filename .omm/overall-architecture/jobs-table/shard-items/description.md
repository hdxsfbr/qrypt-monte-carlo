One item per recorded shard (key JOB#<id> / SHARD#<4-digit index>). DONE items hold sum_hex/sum_sq_hex (exact float.hex), sum, n, duration_ms, attempts; FAILED items hold error and attempts. Written by store.record_shard in a TransactWriteItems together with an ADD on the job's counter; the Put is conditional on attribute_not_exists(pk), which makes duplicate SQS deliveries no-ops. Read back by store.shard_items with paginated consistent queries.
