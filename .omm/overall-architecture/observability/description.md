Alerting and dashboard (infra/modules/observability/main.tf) plus the in-code emitters in src/handlers/common.py. Handlers write CloudWatch Embedded Metric Format lines to stdout in namespace QMC with one dimension Environment (JobsSubmitted, PathsSimulated, EntropyKiB, ShardFailures, QryptErrors, ShardDurationMs) and structured JSON logs. Terraform defines an SNS alert topic with an email subscription, four alarms and one dashboard.
