src/handlers/common.py emit_metrics() and log_event(). emit_metrics validates names against METRIC_UNITS and writes one EMF JSON line straight to stdout (bypassing logging so Lambda passes it through unchanged); context fields such as job_id and shard are kept as searchable properties, not dimensions. log_event writes structured log lines through the `qmc` logger, which Lambda's JSON log format renders as JSON keys. Neither may include headers, bodies or secrets.
