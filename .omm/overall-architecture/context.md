Built as an assessment project that must stay inside AWS always-free allowances in a dedicated account (us-east-1). This drives the shape: Lambda Function URL instead of API Gateway, SQS instead of Step Functions, a single provisioned DynamoDB table (15 of 25 free capacity units), SSM SecureStrings instead of Secrets Manager, no VPC/NAT. Reproducibility is a core requirement: every job stores its master seed and algorithm version so it can be replayed bit-identically without another Qrypt call.
