Serverless AWS platform that prices a European call option by Monte Carlo simulation, seeded with quantum entropy from Qrypt. A caller submits a job to the API Lambda (Lambda Function URL); the API fetches 1 KiB of Qrypt entropy, stores the job in a single DynamoDB table and fans it out as one SQS message per shard. Worker Lambdas simulate one shard each, record results idempotently, and the last shard combines all results into an estimate with a standard error, a 95% confidence interval and a Black-Scholes reference price. Pure numerical code lives in src/qmc (no AWS calls); thin handlers in src/handlers wire it to AWS; infra/ holds the Terraform root module and the api, workers, data, observability and budget modules.
