The API Lambda qmc-<env>-api (handler handlers.api.handler, python3.13, 512 MB, 10 s timeout) exposed through a Lambda Function URL. Routes: POST /jobs, GET /jobs, GET /jobs/{id}, POST /jobs/{id}/replay, GET /health. Every route is authorized first (bearer key from SSM, or AWS_IAM signing checked by AWS). Unhandled errors become a plain 500 with the request id. Code: src/handlers/api.py plus shared src/handlers/common.py and src/handlers/store.py; infra: infra/modules/api.
