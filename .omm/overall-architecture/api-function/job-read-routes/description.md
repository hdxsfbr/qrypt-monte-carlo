get_job(), mark_stale(), view() and list_jobs() in src/handlers/api.py. GET /jobs/{id} returns status, progress, params, Black-Scholes price, seed info, and result fields; a stored QUEUED job with any finished shard is shown as RUNNING. If a job is still QUEUED 10 minutes after creation, mark_stale lists the missing shards and conditionally sets it PARTIAL with stale=true. GET /jobs pages newest-first through the by_created index (limit 1-100, opaque base64 `next` token validated by store.decode_page_token).
