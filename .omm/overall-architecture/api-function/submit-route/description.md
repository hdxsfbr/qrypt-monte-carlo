submit(), create_job() and enqueue() in src/handlers/api.py. Validates the body with qmc.params.validate_job_request (limits from env), takes a rate slot (store.take_rate_slot, 429 with Retry-After when full), fetches 1 KiB from Qrypt via entropy_factory() (EntropyError -> 502/503 plus QryptErrors metric), derives the master seed (first 32 bytes) and block SHA-256, writes the job item (status QUEUED, gsi1pk JOBS) and sends one SQS message per shard in batches of 10. Returns 202 with the job id. Emits JobsSubmitted and EntropyKiB metrics.
