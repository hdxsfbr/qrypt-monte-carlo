handler() and route() in src/handlers/api.py. Extracts method and rawPath from the Function URL event, runs authorize(), then dispatches by path: /health, /jobs, and /jobs/{uuid}[/replay] matched by JOB_PATH and validated as a canonical UUID. only() returns 405 with an Allow header for the wrong method; unknown paths return 404. HttpError is turned into its response; any other exception is logged and returned as 500 with the request id.
