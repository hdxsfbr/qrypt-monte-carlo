Two SSM Parameter Store SecureStrings, by default /qmc/dev/qrypt_api_key and /qmc/dev/api_key, created out-of-band by scripts/put-secrets.sh. Terraform builds their ARNs from the names only (infra/main.tf locals.ssm_arns) and grants the API role ssm:GetParameter on exactly these two. The API reads them with decryption and caches values for 5 minutes per function instance; /health reads them without decryption to prove they exist.
