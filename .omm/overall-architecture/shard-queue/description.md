SQS standard queue qmc-<env>-shards plus dead-letter queue qmc-<env>-shards-dlq (infra/modules/workers/main.tf). Each message carries {job_id, shard_index, shard_count, paths}. Visibility timeout is 6x the worker timeout, long polling 20 s, retention 1 day; after max_receive_count (default 3) deliveries the message is moved to the DLQ, which keeps messages 14 days. Both queues use SQS-managed encryption.
