The worker Lambda qmc-<env>-worker (handler handlers.worker.handler, python3.13, 1769 MB = one vCPU, timeout 60 s by default) triggered by the shard queue with batch size 1 and maximum_concurrency = worker_concurrency. For each message it loads the job, simulates the shard, records the result idempotently, and if all shards are in, finishes the job as COMPLETE or PARTIAL. Code: src/handlers/worker.py; infra: infra/modules/workers.
