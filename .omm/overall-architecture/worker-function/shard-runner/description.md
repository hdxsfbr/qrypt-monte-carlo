run() in src/handlers/worker.py. Raises InjectedFailure for shards listed in fail_shards when fault injection is on. Otherwise calls qmc.pipeline.run_shard with the job params, master seed and algo_version, then records {state DONE, sum_hex, sum_sq_hex, sum, n, duration_ms, attempts} via store.record_shard, which also increments the job's completed counter in the same transaction. A duplicate delivery is refused and logged. Emits PathsSimulated and ShardDurationMs metrics.
