maybe_finish() and result_fields() in src/handlers/worker.py. When completed + failed equals the shard count, reads all shard items; if any failed the job becomes PARTIAL with failed_shards, otherwise rebuilds exact ShardResults from float.hex values, aggregates them in shard-index order, and writes the estimate, std error, 95% CI, estimate_hex, Black-Scholes price and std_errors_from_black_scholes. For replays it adds replay_check.bit_identical. store.finish_job is conditional on status QUEUED, so only one finisher wins.
