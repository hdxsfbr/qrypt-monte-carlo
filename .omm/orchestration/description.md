Queue-based fan-out of a job into shards. The API publishes one SQS message per shard; a Lambda event source mapping delivers them one at a time to worker instances; failures are retried with short exponential visibility timeouts and, after max_receive_count deliveries, redriven to a dead-letter queue. There is no coordinator: the worker that records the last shard finishes the job (fan-in through DynamoDB counters).
